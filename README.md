\# Permission-Aware Multi-Tenant RAG



A secure Retrieval-Augmented Generation (RAG) system that

provides document-grounded answers while enforcing

tenant-level and user-level access control.



\## Project Status



🚧 In development



\## Goal



Build a multi-tenant RAG system where:



\- Users can query authorized documents

\- Unauthorized documents never reach the LLM

\- Document access is audited

\- Permission changes take effect immediately

\- Security is tested using adversarial queries
